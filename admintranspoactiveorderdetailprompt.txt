Create a complete, production-quality React page for the StoneRate Admin interface named:

StoneRateAdminTransporterActiveOrderDetails.js

PURPOSE

This page allows the StoneRate Admin to view and manage an active delivery order created from an accepted Transporter material request.

The page must allow the Admin to:

- View the Transporter Request ID
- View the Transporter Delivery ID
- View the current order status
- Review Transporter information
- Review the requested material and quantity
- Open the permanent material reference
- Review Seller and pickup information
- Call the Transporter
- Call the Seller
- Navigate to the Seller’s location
- Review all assigned vehicle numbers
- Update the operational status of one or more vehicles
- Select the materials being carried by each vehicle
- Record loading, loaded, and dispatched statuses
- Enter actual loaded quantity when required
- Review the complete order and vehicle activity log

SAVE STATUS ACTION

Primary button:

Save Vehicle Status

On submission, call:

onUpdateVehicleStatus({
  transporterRequestId:
    selectedOrder.transporterRequestId,

  transporterDeliveryId:
    selectedOrder.transporterDeliveryId,

  vehicleIds:
    selectedVehicleIds,

  vehicleNumbers:
    selectedVehicleNumbers,

  materialIds:
    selectedMaterialIds,

  status:
    selectedStatus,

  loadedQuantity:
    selectedStatus === "loaded" ||
    selectedStatus === "dispatched"
      ? loadedQuantity
      : null,

  quantityUnit:
    selectedQuantityUnit,

  adminNote
})

If the parent callback expects one update per vehicle, the page may call it separately for each selected vehicle, but it must:

- Prevent partial silent failures
- Report which vehicle failed
- Refresh backend data after completion
- Avoid updating only local state

VALIDATION

Before submission, validate:

- At least one vehicle is selected
- Every selected vehicle has a valid vehicle number
- At least one material is selected
- A valid status is selected
- Loaded quantity exists for Loaded
- Loaded quantity exists for Dispatched
- Loaded quantity is greater than zero
- Quantity unit is available
- The order is not already completed or cancelled
- Another request is not already saving

Do not trust frontend validation alone.

The backend must validate the update again.
