Build a new responsive Admin page for StoneRate named:

StoneRateAdminUsersPartners.js

Page purpose:
Allow StoneRate Admins to view, filter, search, register, and inspect all platform users and business partners from one unified interface.

The page must support these five user categories:

1. Buyers
2. Stone Sellers
3. Sand Sellers
4. Transporters
5. Admins

IMPORTANT DESIGN DIRECTION

Focus heavily on visual design and usability.

The page must look polished, premium, modern, attractive, and operationally professional. It should not look like a plain database table or basic admin template.

Use the existing StoneRate Admin Rate Requests page as the primary theme reference.

Match its visual language:

- Warm ivory or off-white page background
- StoneRate orange as the primary action color
- Dark navy text
- Soft grey secondary text
- Rounded cards
- Subtle shadows
- Thin warm borders
- Compact uppercase labels
- Status pills
- Smooth hover and press states
- Mobile-first responsive layout
- Professional spacing and typography
- Clear visual hierarchy
- Sticky top controls where useful
- Elegant loading skeletons
- Meaningful empty states
- No horizontal page overflow

Do not redesign the broader Admin navigation. Build only the Users & Partners content page and connect it through the existing Admin menu callback.

Create a premium page header containing:

- Back button

STICKY TABLE HEADER

On desktop and tablet, the records header may remain sticky while scrolling.

The page itself must scroll normally.

Do not use:

height: 100vh;
overflow: hidden;

on the main page or root wrapper.

Use:

min-height: 100vh;
height: auto;

If there is a fixed Admin header, ensure the content wrapper uses:

overflow-y: auto;
min-height: 0;

and does not block page scrolling.
